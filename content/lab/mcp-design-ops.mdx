MCP is most interesting when it makes the design workflow feel less fragmented.

## Working loop

Read the project. Pull design or content context. Make a focused change. Render the result. Check it visually. Keep the reasoning close to the code.

## Portfolio use

The site can read Notion as a source, render case studies, preview local pages, and keep the implementation ready for Vercel.
