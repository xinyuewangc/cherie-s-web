## 排版基准

- 小标题：11px 左右、Mono / uppercase、字距拉开，用来做章节标签。
- 章节标题：桌面端控制在 36-38px 左右，移动端约 24px，避免整页标题过重。
- 正文：15-16px、较松行高，段落之间用更近的距离组织亲密性。
- Insight 模块：保留轻卡片和小标签，不使用左侧彩色描边。
- 底部快速定位气泡：保留，用于快速跳到下一段。

## 风格建议

- 插图尽量用浅底、真实界面局部、少量标注，不要做成纯装饰图。
- 每张插图只解释一个问题，标题短，说明放在 figcaption，不把大段文字压进图片里。
- 如果是流程图，优先横向或轻量泳道，不要用重边框、大色块。
- 视觉重点可以用柔和高亮、圆点编号或局部放大，避免使用左侧彩色描边块。
