A design system is not only a component library. It is a shared way to decide.

## Useful systems

Useful systems explain when a pattern should exist, what problem it solves, what tradeoffs it carries, and how teams can adapt it without breaking the product language.

## Portfolio lens

Each case study is treated as a small system: context, problem, system thinking, design decisions, outcome, and the artifacts that support the story.
